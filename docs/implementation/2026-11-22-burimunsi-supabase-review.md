## Order proposed at the initial review

1. **Qualify and recover scheduled work.** Reconcile the stopped scheduler’s dispatches, verify readiness and restore confirmed recurring processing. Give operators the last confirmed tick, backlog and receiving handset status in Admin. Trace the automatically captured SMS through the ledger, gateway carrier-delivery event and Admin readback.
2. **Harden and complete the workflows.** Add independent Admin re-verification and unique Staff enrollment. Implement held SMS and scoped exception handling. Record payer notice obligations at posting and isolate uncertain carrier outcomes.
3. **Qualify platform operations.** Establish synthetic hosted staging, monitored provider budgets, least-privilege SQL/Edge settings and a baseline for latency and failures. Prioritize keyset and index improvements using that baseline. Add private Realtime and Queues when a measured workflow benefits.
